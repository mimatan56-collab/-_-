# Starter HTML Project

This repository contains a simple static website starter built with HTML, CSS, and JavaScript.

## Files
- `index.html` - Main page structure
- `style.css` - Page styling
- `script.js` - Small interactive behavior

## Run locally
Open `index.html` in a browser or serve the folder locally with a simple web server.

Example:
```bash
python -m http.server 8000
```
Then visit `http://localhost:8000`.
